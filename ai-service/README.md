# AI Service Prompt Templates, Tool Contracts & Evaluation Dataset

This directory stores:
- Provider-agnostic system prompts enforcing strict grounding in deterministic astrological evidence.
- JSON Schema contracts for the 16 deterministic AI tools (`getBirthProfile`, `getNatalChart`, `getPlanetPositions`, `getHouseAnalysis`, `getNakshatra`, `getDivisionalChart`, `getDasha`, `getTransit`, `getDrishti`, `getPlanetStrength`, `getHouseStrength`, `getYogas`, `classifyQuestion`, `getQuestionFramework`, `buildEvidence`, `buildReasoning`, `findTimeWindows`).
- Evaluation datasets (`eval_questions.json`) used in Phase 22 to verify zero-hallucination compliance.
